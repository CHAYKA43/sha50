# **sha50**
Мой алгоритм хеширования, который я написал иза того что мне было нечего делать.
## Как он работает?
(я если честно сам запутался поэтому дам обьяснение от нейросети 🥰 )

`sha50` — это экспериментальный криптографический хеш-алгоритм, созданный в учебных целях.  
Он преобразует **любой текст** в **уникальную строку из 50 шестнадцатеричных символов**.

### 🔐 Основные свойства

- **Фиксированная длина**: всегда 50 символов на выходе.
- **Детерминированность**: один и тот же вход → один и тот же хеш.
- **Лавинный эффект**: изменение даже одного символа меняет ~88% хеша.
- **Устойчивость к коллизиям**: повторяющиеся тексты разной длины дают разные хеши.
- **Многослойная структура**: данные проходят два полных цикла перемешивания.

### ⚙️ Как это работает?

1. **Нормализация до 2000 байт**  
   - Если текст короче 2000 байт — дополняется по детерминированной формуле, зависящей от длины исходного текста в символах.  
   - Если длиннее — обрезается до 2000 байт с циклическим сдвигом.

2. **Первый раунд перемешивания**  
   - Каждый байт увеличивается на `1999 + len(исходный_текст)`.  
   - Затем применяется **кольцевой лавинный эффект**: каждый байт складывается с предыдущим (а первый — с последним).

3. **Преобразование в hex и прореживание**  
   - Результат (2000 байт → 4000 hex-символов) превращается в строку.  
   - Берётся **каждый 5-й символ** → получаем ~800-символьную строку.

4. **Второй раунд перемешивания**  
   - Эта строка снова кодируется в байты (как текст в UTF-8).  
   - Применяются **те же два шага перемешивания**, но уже к новым данным.

5. **Финальная обрезка до 50 символов**  
   - Из полученного hex-хеша (обычно >1000 символов) вырезается **подстрока длиной 50**,  
     начиная со смещения, зависящего от длины хеша.

### 🧪 Пример использования

```python
from sha50 import sha50

h = sha50("Секретный пароль!").sum()
print(h)  # Например: 5f0379209a3ee054c73cdf852c9f18be2fa315bc32a61dc46a
```
